Calesteria Programming Language Specification
 - File Extension: .caria
 - Transpiles to JavaScript (Hono + better-sqlite3)
 - Types: Int, Float, Str, Bool, Nil, List<T>, Map<K,V>, T?, Result<T,E>
 - Keywords: fn, let, mut, ret, pub, mod, use, if, else, match, for, while, in, break, struct, enum, trait, impl, self, as, is, route, view, query, serve, state, test, nil, true, false, and, or, not
 - Syntax Features:
   - String interpolation: "Hello {name}"
   - Error propagation operator: ?
   - Routes: route GET "/path" -> fn(c) { c.text("ok") }
   - SSR View templates: view Page(user) { <div>"Hello, {user.name}"</div> }
   - Database queries: query<User>("SELECT * FROM users")
   - Watch Mode: calesteria dev <file>
   - Testing Framework: test "name" { assertEq(a, b) }
