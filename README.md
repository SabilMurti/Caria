# Calesteria

> A programming language for the vibecoding era.

## What is Calesteria?

Calesteria is a general-purpose programming language designed for AI-first code generation. It prioritizes token efficiency, zero-ambiguity syntax, and built-in web primitives — so LLMs generate better code with fewer tokens.

- **Extension:** `.caria`
- **Transpiles to:** JavaScript (Phase 1)
- **Built with:** Rust
- **Created by:** Sabil Murti ([@SabilMurti](https://github.com/SabilMurti))

## Quick Start

```bash
calesteria new my-app
cd my-app
calesteria run
```
